# Santiago Goncalvez – Portfolio Frontend

Portfolio web personal donde presento mis proyectos, habilidades y formación como Frontend Developer con foco en React y TypeScript.

El objetivo de este sitio es mostrar mi trabajo de forma clara, rápida y profesional, poniendo especial atención en el rendimiento, la arquitectura del código y la experiencia de usuario.

## 🚀 Tecnologías utilizadas

- Astro
- TypeScript
- Vite
- Tailwind CSS
- Vitest (tests unitarios e integrales)

## ✨ Características principales

- Arquitectura liviana y rápida
- Diseño responsive y accesible
- SEO y Open Graph optimizados
- Showcase de proyectos con casos reales de frontend
- Código limpio, mantenible y escalable
- Enfoque en buenas prácticas de performance y UX

## 📁 Proyectos destacados

- **Tech Test: Data Management Dashboard**  
  Dashboard con filtrado avanzado, ordenación multicapa y manejo de estado asíncrono.

- **Hacker Stories (Hacker News Client)**  
  Cliente avanzado con scroll infinito, persistencia de favoritos, historial de búsqueda, routing y tests unitarios e integrales con Vitest.

- **Admin User Management System**  
  Aplicación CRUD con estado global robusto y sistema de actualización optimista con rollback usando Redux Toolkit.

- **Tu País**  
  Juego de adivinanzas de banderas desarrollado en Vanilla JavaScript, con arquitectura inspirada en Flux y estado global.
